# AI YouTube Summarizer

An AI-powered web application that summarizes YouTube videos and generates:
- Video summaries
- Smart notes
- Timestamps
- Quiz questions

Built using React, Vite, Tailwind CSS, Python, Whisper, and LLM APIs.
